
# 📰 EXPRESS-60

EXPRESS-60 is a Flask-based NLP web application that summarizes real-time news articles into concise 60-word highlights, helping users quickly understand the key information.

## 🚀 Features

- Summarizes news articles into 60-word highlights
- Fetches real-time news using REST APIs
- Fast and easy-to-use web interface
- Reduces reading time while preserving key information

## 🛠️ Tech Stack

- Python
- Flask
- NLTK
- Newspaper3k
- REST APIs
- HTML
- Css
- 

## ▶️ Installation

```bash
git clone https://github.com/TusharRaj0/EXPRESS60.git

cd EXPRESS60

pip install -r requirements.txt

python app.py
```

## 📂 Project Workflow

1. Fetch real-time news articles.
2. Extract article content.
3. Process text using NLTK.
4. Generate concise 60-word summaries.
5. Display summaries through the Flask web interface.
